## Wager (shared — see RULES.md)

- Ante **1 Sight**, once/window — **Veiled or Witnessed**.
- Flip now: **Heads** steal 1 power this Resolve + optional **Up the Ante**; **Tails** −1 Sight + Re-Veil.
- Witnessed Heads win at Resolve → Trick Eclipse (Favor spend if available).

Printed `CardDef.text` is source of truth for each rider.
