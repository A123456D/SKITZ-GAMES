# Ink Abyss — Wave 2 (Erase support pack)

Five kit tools. Wave 1 keeps lane roles; Wave 2 makes Erase a craft.

| Card | Type | Cost | Role |
|------|------|------|------|
| **Pale Bailiff** | Figure | 4E / 2W · V2 / W5 | Erase police |
| **Blackwater Shrine** | Site | 2E | Erase bank |
| **Gulf Urn** | Vessel | 3E / 2W · V1 / W3 | Break spreader |
| **Smother Cord** | Relic | 2E · Graft | Erase chain |
| **Ashen Tithe** | Rite | 1E | Cash Mark |

## Pale Bailiff — Erase police
- **Veiled:** Whenever an enemy Figure in another altitude becomes Forced Exposed, Stain a different enemy Figure if able.
- **Revelation:** Stain the enemy Figure here if able. If it was already Stained, Blind this altitude this turn.

## Blackwater Shrine — Erase bank
- **Site.** When an enemy Figure here becomes Forced Exposed, gain 1 Sight.
- When you Stain an enemy Figure here, gain 1 Sight.

## Gulf Urn — Break spreader
- **Vessel.** On play, tuck a Figure from hand as Inhabitant if able.
- **Revelation:** Stain the enemy Figure here if able.
- When this Falls or is Forced Exposed: Stain an enemy Veiled Figure if able, then Blind that Figure’s altitude this turn.

## Smother Cord — Erase chain
- **Graft:** +1 power while host Witnessed.
- When host Forces Exposed an enemy, Stain another enemy Veiled Figure if able; if host is on Mid, also gain 1 Sight.

## Ashen Tithe — Cash Mark
- Choose an altitude. If the enemy Figure there is Stained, gain 1 Sight and draw 1. If it is also Veiled, Blind that altitude this turn.

## Pack sketch
Shrine banks Erase Sight → Bailiff police turns Forced Expose into board Marks → Cord chains Erase into another Mark → Urn breaks for Mark+Blind → Tithe cashes Marks for cards.
