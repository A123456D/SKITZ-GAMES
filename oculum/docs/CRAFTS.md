# OCULUM — Crafts (soft reboot)

Heresies are **crafts** (Shadowverse-style factions), not single archetypes.

| Layer | Meaning |
|-------|---------|
| **Craft** | Faction + private keyword kit (Ink = Stain/Erase, Motley = Stance/Trick, Bellward = Toll/Lure/Resonance, Scar = Breach/Open, Lumen = Halo/Blaze/Sustain, Ruin = Tempt/Brand/Devour) |
| **Verb** | One-word craft fantasy |
| **Archetype** | A deck shape *inside* a craft (Teach is the flagship; more come with waves) |
| **Shared law** | Veil · Witness · Sight · Altitude · Resolve · Strain · Fall · Blind · Eclipse |
| **Splash** | A few off-craft cards; never a 50/50 verb split |

**Craft uniqueness test:** if you strip names/art and it still plays like a generic SV class with eye stickers, reject it. Veil / Witness / Altitude must matter.

## Dual-mode Figures

Every **Figure** prints:

1. **Veiled:** — active while Veiled (Hold / Win Resolve / continuous / rival-act)
2. **Revelation:** — fires **once** on first Witness

Shared law also includes **Re-Veil**, **Overwrite**, and **Scrutiny** (see RULES.md). Teach packs must use **in-craft teamwork** (Stain / Stance / Toll / Breach / Halo / Tempt / Eclipse / Inhabitant), not solo goodstuff.

## Revelation / effect uniqueness law

Shared craft **grammar** is fine (Stain, Stance, Blind). Each card’s **payload** must fail the blackout test: *If I hide the name, could this be three other cards in the craft?* → must be **no**.

Uniqueness = **gameplay fork** (timing, target, rider, asymmetry) + **character** — not flavor-only wording.

- **Figures:** Veiled line + Revelation each unique; Revelation = SV Fanfare energy.
- **Sites / Relics / Rites / Vessels:** Still unique triggers — not generic “+1 / Stain once.”
- **Anti-pattern:** `Enter Stance B` / `Switch Stance. Draw 1` / `Stain an enemy Veiled` as the *entire* identity.

## Figure glamour

**Most** female-presenting Figures: intentional **sexiness / glamour** (pose, silhouette, cloth, beauty+wrongness). Not every card — elders, horrors, comic underlings, abstract Sites/Relics exempt. Premium CCG allure, not softcore.

**Gender mix / anatomy:** do not Motley-stack glamorous **human** women or exaggerated busts. Bellward Toll Wave 1 cast is locked: **2 male humans** (Debt Walker, Veil Ringer) · **1 human female** (Parasol Debtor — modest proportions) · **2 creature females** (Bell Siren yokai, Clapper Cantor bell-spirit). Scar Breach Wave 1 cast is locked: **2 male humans** (Rivet Vanguard, Highscar Lancer) · **1 human female** (Scarsteel Cleaver — sexy-aggressive warrior, not Motley court glam) · **1 war-spirit** (Slag Reaper) · **1 living war-standard** (Ember Banner — non-human). Scar Breach Wave 3: **2 male humans** (Cliffbrand Captain, Lowscar Warden) · **1 human female** (Ember Herald — sexy-aggressive). **Velvet Ruin** Wave 1: **3 ♀ demons** (Thorn Liaison elegant predator · Crimson Vow near-human succubus · Spire Hunger fully inhuman) — mostly-female demonic craft is intentional; still **no exaggerated bust default**; Wave 2 adds **Vespera** (♀ Low demon); Wave 3 adds **Thorncrown** (♀ High) · **Siltthorn** (♂ incubus Low) · **Brandlace** (♀ Mid). Later waves may add sparse incubus/horror. Female allure without oversized breasts; spirits/standards read non-human.
