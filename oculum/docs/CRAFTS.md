# OCULUM — Crafts (soft reboot)

Heresies are **crafts** (Shadowverse-style factions), not single archetypes.

| Layer | Meaning |
|-------|---------|
| **Craft** | Faction + private keyword kit (Ink = Stain/Erase, Motley = Stance/Trick, Bellward = Toll/Lure/Resonance, Scar = Breach/Open; Dusk/Bonewick shelved) |
| **Verb** | One-word craft fantasy |
| **Archetype** | A deck shape *inside* a craft (Teach is the flagship; more come with waves) |
| **Shared law** | Veil · Witness · Sight · Altitude · Resolve · Strain · Fall · Blind · Eclipse |
| **Splash** | A few off-craft cards; never a 50/50 verb split |

**Craft uniqueness test:** if you strip names/art and it still plays like a generic SV class with eye stickers, reject it. Veil / Witness / Altitude must matter.

## Dual-mode Figures

Every **Figure** prints:

1. **Veiled:** — active while Veiled (Hold / Win Resolve / continuous / rival-act)
2. **Revelation:** — fires **once** on first Witness

Shared law also includes **Re-Veil**, **Overwrite**, and **Scrutiny** (see RULES.md). Teach packs must use **in-craft teamwork** (Stain / Stance / Toll / Breach / Eclipse / Inhabitant), not solo goodstuff.

## Revelation / effect uniqueness law

Shared craft **grammar** is fine (Stain, Stance, Blind). Each card’s **payload** must fail the blackout test: *If I hide the name, could this be three other cards in the craft?* → must be **no**.

Uniqueness = **gameplay fork** (timing, target, rider, asymmetry) + **character** — not flavor-only wording.

- **Figures:** Veiled line + Revelation each unique; Revelation = SV Fanfare energy.
- **Sites / Relics / Rites / Vessels:** Still unique triggers — not generic “+1 / Stain once.”
- **Anti-pattern:** `Enter Stance B` / `Switch Stance. Draw 1` / `Stain an enemy Veiled` as the *entire* identity.

## Frame laws (soft reboot)

| Craft | Frames |
|-------|--------|
| **Ink Abyss** | **Cream / bone / pale stone** family; unique architecture per card; black drip accents — never one cloned template |
| **Motley Masquerade** | Purple/teal/gold DNA; unique per card; **ornate Masquerade** filigree (rich OK — not simplified) |

| **Scar Breach** | **Open-wound / strap DNA** (unique architecture per card, shared family — like Ink cream): bone-ash straps · torn cloth · eye-brands in wound-seams · ember slits — **not** one cloned frame, **not** riveted iron plate, not Motley masks, not Ink drip, not Toll bells; bodies = harness / brands / exposed skin; Ink-style varied portraits; palette charcoal strap / rust-blood / bone-ash / ember |
| **Dusk Ledger** (shelved) | **Copper / charcoal / dusk-orange** canyon ledger frames; unique per card; eclipsed-sun / debt-coin accents |
| **Bonewick** (shelved) | **Bone-white cracked coastal shrine** frames; matte bone, royal blue banners/shards, pale sea — not Delft, not Ink cream-drip, not Motley purple, not Dusk copper |

## Figure glamour

**Most** female-presenting Figures: intentional **sexiness / glamour** (pose, silhouette, cloth, beauty+wrongness). Not every card — elders, horrors, comic underlings, abstract Sites/Relics exempt. Premium CCG allure, not softcore.

**Gender mix / anatomy:** do not Motley-stack glamorous human women or exaggerated busts. Bellward Toll Wave 1 cast is locked: **2 male humans** (Debt Walker, Veil Ringer) · **1 human female** (Parasol Debtor — modest proportions) · **2 creature females** (Bell Siren yokai, Clapper Cantor bell-spirit). Scar Breach Wave 1 cast is locked: **2 male humans** (Rivet Vanguard, Highscar Lancer) · **1 human female** (Scarsteel Cleaver — sexy-aggressive warrior, not Motley court glam) · **1 war-spirit** (Slag Reaper) · **1 living war-standard** (Ember Banner — non-human). Scar Breach Wave 3: **2 male humans** (Cliffbrand Captain, Lowscar Warden) · **1 human female** (Ember Herald — sexy-aggressive). Female allure without oversized breasts; spirits/standards read non-human.
