# OCULUM beta

Things only fully exist when **Witnessed**.

GPU-first mobile CCG — painted canyon + cards, quiet CSS chrome, WebGL2 board, touch HUD, Veil / Witness across High · Mid · Low.

## Play

```bash
npm install
npm run dev
```

Open the LAN URL on your phone (Vite prints it). Portrait preferred.

## Ship to SKITZ site

```bash
npm run ship
```

Copies `dist/` → `website/public/games/oculum/web/`. Play path: `/games/oculum/play/`.
