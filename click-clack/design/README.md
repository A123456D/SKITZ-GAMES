# Skitz Controller — Design Prototype

Interactive dark-tech UI mock for visual iteration before Android.

```bash
cd design
npm install
npm run dev
```

Open the local URL (usually `http://localhost:5173`).

- **Connect / Pad / Keys** tabs
- **Landscape** toggle (top-right) to preview rotated keyboard
- On **Pad**, tap **Keys** handle to swipe up the keyboard sheet

No Bluetooth — design only.
