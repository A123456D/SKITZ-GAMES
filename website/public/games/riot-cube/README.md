# RIOT CUBE web build

Mobile-first sticker match puzzle: twist rows/columns (cube-slice moves), clear matches, beat goals.

## Dev

```bash
cd riot-cube
npm install
npm run dev
```

## Ship to site

```bash
cd riot-cube
npm run ship
```

Copies `dist/*` → `website/public/games/riot-cube/web/`.

Play path: `/games/riot-cube/play/`
