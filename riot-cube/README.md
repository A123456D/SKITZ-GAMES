# RIOT CUBE

Twist slices. Rip sticker matches. Clear the riot.

## Play

```bash
cd riot-cube
npm install
npm run ship
```

Then open `/games/riot-cube/play/` on the site.

Dev: `npm run dev` (port 5175).
