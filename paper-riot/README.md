# PAPER RIOT

Candy Crush–style sticker match-3. Punk classroom look. Classroom stickers from Riot Cube.

Tagline: **RIP. MATCH. REPEAT.**

## Play

```bash
npm install
npm run dev
```

Ship into the site:

```bash
npm run ship
```

Open `/games/paper-riot/play/` on the website.

## Status

Playable vertical slice: home menu, 6×8 board, swap-to-match, cascades, goals, moves. Power-ups / obstacles / daily / shop land as you drop more assets.
